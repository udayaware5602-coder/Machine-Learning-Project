
# 🤖 K-Means Clustering – Facebook Live Engagement

Welcome to my **K-Means Clustering Machine Learning Project**! 🚀

This project uses **K-Means Clustering** to analyze Facebook Live posts and group them based on their engagement patterns. The project includes data preprocessing, exploratory data analysis, clustering, PCA visualization, and an interactive Streamlit dashboard.

---

## 📌 Project Contents

- 📊 Facebook Live Dataset
- 🧹 Data Preprocessing
- 📈 Exploratory Data Analysis (EDA)
- 🔄 Feature Transformation
- 📏 Feature Scaling
- 🤖 K-Means Clustering
- 📐 Silhouette Score Analysis
- 🧩 Cluster Analysis
- 📉 PCA Visualization
- 🌐 Streamlit Web Application
- 💾 Model Export
- 📄 Clustering Report

---
