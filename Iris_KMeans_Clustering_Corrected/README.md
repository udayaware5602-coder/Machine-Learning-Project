# 🌸 Iris Species Classification – Machine Learning Project

Welcome to the **Iris Species Classification** project! 🚀 

This repository contains an end-to-end Machine Learning project that classifies Iris flowers into their respective species (**Setosa**, **Versicolor**, and **Virginica**) based on sepal and petal measurements. The project features complete data preprocessing, exploratory data analysis (EDA), model training, evaluation, and an interactive **Streamlit** dashboard for real-time predictions.

---

## 📌 Project Contents

- 📊 **Iris Dataset (`Iris.csv`)**
- 🧹 **Data Preprocessing & Cleaning**
- 📈 **Exploratory Data Analysis (EDA)**
- 🤖 **Machine Learning Classification Models**
- 📐 **Model Evaluation & Performance Metrics**
- 🌐 **Interactive Streamlit Web Application (`app.py`)**
- 💾 **Model Serialization (`.pkl`)**
- 📄 **Project Documentation (`README.md`)**

---

## 🛠️ Technologies & Libraries Used

- **Language:** Python
- **Data Manipulation:** NumPy, Pandas
- **Data Visualization:** Matplotlib, Seaborn, Plotly
- **Machine Learning:** Scikit-learn
- **Model Serialization:** Joblib / Pickle
- **Web Framework:** Streamlit
- **Development Environment:** Jupyter Notebook / VS Code
